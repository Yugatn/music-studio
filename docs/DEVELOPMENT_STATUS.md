# Development status

## Implemented

- Cross-platform MusicProject core.
- Versioned .yms codec and portable project storage.
- Project notes and tags.
- Shared note editing and undo/redo.
- Composition revision graph.
- AI composition context for iterative work after manual edits.
- Musical metrics and AI recommendations.
- Explicit AI change plans.
- Persistent automation lanes for velocity, pitch and timing.
- Android Compose prototype with Piano Roll and Curve Lab.
- Platform-neutral sync revision model.

## Next implementation priorities

1. Connect macOS Curve Lab to persistent AutomationLane data.
2. Apply automation lanes to notes through explicit, reversible commands.
3. Add project notes UI and save/load metadata in macOS.
4. Connect Android Piano Roll and Curve Lab to MusicProject.
5. Add iPad/iPhone SwiftUI client.
6. Add cross-device sync transport.
7. Add audio playback/render engine.
